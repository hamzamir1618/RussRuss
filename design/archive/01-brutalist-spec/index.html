Name

Say it twice.

RUSSRUSS repeats itself, and the wordmark can play on that: one half full, the other pressed out to an outline. That's the same solid-over-outline move the hero makes. There are four lockups below, with A recommended.

Direction

Flat, loud, hand-cut.

The page should feel like a sticker sheet laid on a print grid. Highlighted keywords link to a live demo further down.

Grid & structure

asymmetrical-editorial brutalist-grid-broken overlapping-z-index-layers content-shift-on-scroll offset-split-screen high-density-whitespace

Dense clusters of information (badges, prices, stats) separated by large empty fields. Nothing sits evenly spaced.

Motion & kinetic type

infinite-horizontal-marquee variable-font-weight-animation text-stroke-fill-transitions scrub-driven-parallax rotational-skew-on-drag letter-spacing-expansion mask-reveal-clip-path

Motion is mostly typographic. Product imagery moves only through parallax and drag.

Visual treatment

hyper-saturated-cutouts hard-drop-shadows-no-blur glassmorphism-free flat-matte-accents high-contrast-monochrome-pairing condensed-impact-type photographic-floating-stickers

Color only ever comes from the fruit: in the photo, or as a flat fill keyed to a flavor.

Do / don't

Four calls that keep it off the generic path

Every shadow is offset ink with zero blur. Elevation goes up by growing the offset.

One pigment per surface. No gradients, and no cyan or purple anywhere.

Panels over busy layers are solid white with an ink edge.

Claims are stated as measurements, set in mono.

Font sourcing

Syne, Plus Jakarta Sans and Space Mono are free on Google Fonts, and this page uses them. Syne's weight axis runs 400–800, so the brief's 300→900 scrub becomes 400→800 here; the effect still reads clearly. Clash Display is a free Fontshare face that stops at 700. Monument Extended and PP Neue Montreal need paid licences. Syne at 800 is wide, not condensed: if you want true condensed impact type, that's a font swap (question 2).

Rules

  • PropertiesAnimate transform, opacity, clip-path and font-variation-settings only. Never animate layout.
  • Paused framesEvery scene must read as a finished composition if the user stops scrolling halfway.
  • Reduced motionNo loader, no pins, no particles. Sections render in the static layout with all content visible.
  • MobileNo cursor or pointer depth, and half the particles. Pins stay, because they work with touch scrolling.

Image prompts

Nano Banana prompts.

One prompt per asset. Each card names the scene its image animates in, and its angle is chosen for that motion. Copy adds the style block below to the prompt, so every image shares the same light and background. The colored top edge marks the flavor.

Style block · appended to every prompt

Photorealistic high-end beverage advertising photograph with a dynamic, dramatic composition. Hard key light from the upper left plus a strong white rim light from behind on the right, giving punchy contrast, sharp specular highlights and crisp edges. Motion frozen with a 1/8000 second strobe, everything tack sharp. The subject is isolated on a pure, flat, seamless white background with no gradient, no floor, no cast shadow, no reflection and no vignette, so it can be cut out cleanly. Vivid, hyper-saturated but true-to-life fruit colors. No text, no logos, no hands, no props, no extra objects.

  1. Lock the hero cup first. Iterate P01 until the cup, lid and condensation are right. It's the reference for P02.
  2. Lock the reel master. P03 sets the tossed pose. Attach it to P04–P06 so all four cups match exactly. Attach S01 to S03.
  3. Keep the angles. The camera angle in each prompt is there because the animation depends on it. If a result comes back straight-on, regenerate and don't use it.
  4. Frame and resolution. Set the aspect ratio shown on the card, at the highest resolution available (2K or 4K).
  5. Cut out. Nano Banana can't output transparency, so remove the background afterwards. If white foam or rim light gets eaten, regenerate on "flat neutral mid-grey background".

Open questions

Before we build.

These change what gets built. Everything else in this document can go ahead as written.

Q1 · Brand

Which wordmark?

Lockup A is set in the hero for now. Pick A–D, or say if you want a custom-drawn logotype instead of set type.

Q2 · Type

Syne, or a true condensed face?

Syne is free and covers 400–800 but sets wide. Monument Extended or PP Neue Montreal need licences. Clash Display (free) stops at 700.

Q3 · Color

Small text on green
