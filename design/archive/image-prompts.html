RUSSRUSS image prompts

Four art directions for the landing page, each with its own asset set for Nano Banana. Every prompt is split into labeled fields, so the subject, pose, camera position and framing are each stated on their own and can't blur together. Copy builds the full prompt in this order:

SHOTSUBJECTPOSECAMERAWHAT THE ANGLE SHOWSFRAMINGLIGHTINGBACKGROUNDSTYLEAVOID

Workflow

  1. Generate prompt 01 of a direction first. Then attach it as the reference for 02 so the flavor set matches exactly.
  2. Cutouts come out on white for background removal. Scenes are full-frame backgrounds, so don't cut them out.
  3. Save with the filename shown into assets/A … assets/D in the project folder, and I'll wire them in.

If the angle still comes back wrong

  1. Fix it with an edit, not a re-roll. Keep the result and reply: Keep everything the same, but move the camera below the cup so it looks up at it. Nano Banana is much better at changing an existing image than at getting the angle on the first try.
  2. Tilt in a second step. If the pose is the problem, get the object right upright first, then send: Rotate the cup so its top leans to the right, toward 1 o'clock.
  3. Attach an angle reference. Add any photo or rough sketch that has the camera angle you want, and add: Match only the camera angle and tilt of the second image. Ignore its subject and colors.
  4. Use clock directions, not degrees. The prompts already say "top leans toward 1 o'clock", which models follow more reliably than angle numbers.
